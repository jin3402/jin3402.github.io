> CORS·스냅샷·광고·프로모션·콘텐츠 필터까지, **미니앱 실서비스 제약을 뚫으면서** 할인 게임 큐레이션 제품을 끝까지 만든 프로젝트입니다.

- **GitHub:** [jin3402/gamsale](https://github.com/jin3402/gamsale)
- **플랫폼:** Apps in Toss WebView · TDS
- **역할:** 개인 / 기획·개발·배포 전반

게임 할인은 Steam, Epic, Xbox, PlayStation, Nintendo에 흩어져 있습니다. 한곳에 모으면 쓸모 있지만, 토스 WebView에서는 콘솔 스토어 API가 CORS로 막히는 경우가 많습니다. TDS UI, 광고, 프로모션 검수, 선정성 기준까지 같이 맞춰야 해서 `fetch`만으로는 출시까지 갈 수 없었습니다.

## 1. 한 화면에서 플랫폼을 가르기

피드 상단은 `전체 / Steam / Epic / Xbox / PlayStation / Nintendo` 칩입니다. `전체`가 기본값이고, 칩을 바꾸면 같은 카드 레이아웃으로 해당 스토어만 남습니다. 오른쪽 하트 배지는 위시리스트 개수입니다. 화면의 `2`는 이미 찜한 게임이 두 개 있다는 뜻입니다.

각 카드는 키아트를 배경으로 씁니다. 왼쪽 위 빨간 배지가 할인율, 오른쪽 위 하트가 찜, 아래가 플랫폼·타이틀·할인가/정가입니다. 예를 들어 PlayStation `Dead Space Digital Deluxe Edition`은 **-85%**, 115,985원 → **17,386원**입니다. 같은 화면에 Steam `Yoku's Island Express`처럼 다른 스토어 딜이 섞여 들어옵니다.

Steam/Epic은 CheapShark를 실시간으로 부르고, Xbox/PS/Nintendo는 빌드 타임 스냅샷을 씁니다. 운영 WebView에서 콘솔 API가 CORS로 실패하기 때문입니다. `prebuild`가 실패하면 이전 스냅샷을 유지해 빈 화면을 피합니다.

상위 게임이 항상 같으면 피드가 지루해져서, 할인율 상위 풀을 **세션 시드로 셔플**합니다. 초기에는 약 150개만 보여주고, 끝까지 내린 뒤에만 Steam/Epic 다음 페이지를 추가로 받습니다.

![겜세일 피드. 전체 탭과 Dead Space, Ghost Recon, Yoku's Island Express 할인 카드](/assets/img/posts/gamsale-list.png)
{: .w-50 .shadow .rounded-10 }
_플랫폼 칩, 할인율 배지, 할인가/정가가 한 카드에 들어갑니다. 하트는 카드 탭과 분리되어 있어 찜만 할 수 있습니다._
{: .fig-caption }

## 2. 카드를 누르면 스토어로 갈지, 공유할지

카드 본문을 탭하면 하단 시트가 열립니다. 할인율·타이틀·플랫폼을 한 번 더 확인하고, 선택은 두 가지입니다.

- **스토어에서 보기** — 해당 플랫폼 상품/검색 URL로 이동합니다. 이 시점에만 전면 광고를 보여 줍니다. 예전에는 플랫폼 탭을 바꿀 때마다 광고가 떠서 탐색이 끊겼고, 지금은 **돈을 쓰러 나가는 순간**에만 붙입니다.
- **공유하기** — 게임 이름, 할인율, 가격, 스토어 링크를 공유 시트로 보냅니다. 토스 네이티브 공유가 없으면 Web Share API로 폴백합니다.

하트는 시트와 별개입니다. 실수로 스토어 이동/광고가 뜨지 않게, 찜은 카드 모서리에서만 동작합니다. 위시리스트는 기기 로컬에 저장됩니다.

![Dead Space 액션시트. 스토어에서 보기와 공유하기](/assets/img/posts/gamsale-actionsheet.png)
{: .w-50 .shadow .rounded-10 }
_피드에서 고른 딜의 다음 행동입니다. 스토어 이동 전에만 전면 광고가 붙고, 공유는 광고 없이 바로 열립니다._
{: .fig-caption }

## 3. Steam 딜은 실시간이고, 가격은 원화로 환산합니다

같은 화면을 `Steam` 칩으로 좁힌 모습입니다. Xbox·PlayStation·Nintendo는 빌드 타임 스냅샷이라 목록이 배포 시점에 고정되지만, Steam과 Epic은 CheapShark를 실시간으로 부르기 때문에 앱을 열 때마다 목록이 달라집니다.

CheapShark는 가격을 USD로 내려줍니다. 화면에 보이는 원화는 `open.er-api.com`에서 받은 USD→KRW 환율을 1시간 캐시해 곱한 값입니다. 환율 호출이 실패하면 `FALLBACK_USD_KRW_RATE`(기본 1,350원)로 떨어지기 때문에 가격 칸이 비는 일은 없습니다. `Serious Sam Classic: The Second Encounter`가 8,229원에서 **1,223원(-85%)** 으로 잡힌 게 그 결과입니다.

중복 제거는 타이틀 문자열 기준이라, `The First Encounter`와 `The Second Encounter`처럼 이름이 다른 별개 상품은 둘 다 남습니다. 같은 시리즈가 연달아 보이는 건 이 때문입니다.

![겜세일 Steam 탭. Gorogoa와 Serious Sam 할인 카드, 그리고 Serious Sam Classic: The First Encounter 액션시트](/assets/img/posts/gamsale-steam-actionsheet.png)
{: .w-50 .shadow .rounded-10 }
_Steam으로 좁힌 피드와 액션시트입니다. 표시된 원화는 CheapShark의 USD 가격을 환율로 환산한 값입니다._
{: .fig-caption }

## 데이터와 광고가 붙는 위치

닌텐도 목록은 스냅샷 생성 시점과 런타임에 성인·선정성·저품질 키워드를 이중 필터합니다. 미니앱 심사에서 이름이 반려된 적도 있어서, 콘솔 등록명과 `brand.displayName`을 `겜세일`로 맞춰 두었습니다.

## 개발하며 겪은 이슈

| 이슈 | 결정 |
|------|------|
| 콘솔 스토어 CORS | 빌드 타임 스냅샷 + 이전 스냅샷 폴백 |
| 상위 게임이 항상 같음 | 할인율 상위 풀을 세션 시드로 셔플 |
| 탭 전환마다 광고 | 스토어 이동 시에만 전면 광고 |
| 리스트를 무한으로 늘리고 싶음 | 150개 이후 Steam/Epic만 페이지 단위 로드 |
| 닌텐도 선정성 타이틀 | 스냅샷/런타임 이중 필터 |
| 미니앱 이름 반려 | 콘솔 등록명과 `brand.displayName`을 동일하게 맞춤 |

## 기술 스택

- Language / UI: TypeScript, React 18, Vite
- Platform: `@apps-in-toss/web-framework`
- Design System: `@toss/tds-mobile`
- Data: CheapShark, PlayStation GraphQL, Xbox Store Edge, Nintendo KR Store
- Ops: `prebuild` 스냅샷, `.ait` 번들 배포

## 마치며

이 프로젝트에서 배운 것은 API를 많이 붙이는 일이 아니라, **피드에서 스토어로 나가는 순간까지 WebView 제약 안에서 제품을 완성하는 일**이었습니다. 위 화면이 그 출시 형태입니다.
