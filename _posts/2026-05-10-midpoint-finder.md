친구들과 만날 때 “어디서 볼까?”를 정해주는 **앱인토스 미니앱**입니다. 여러 출발지를 입력하면 중간 좌표를 계산하고, 주변 맛집·카페·볼거리까지 추천합니다.

- **GitHub:** [jin3402/midpoint-finder](https://github.com/jin3402/midpoint-finder)
- **플랫폼:** Apps in Toss WebView · TDS
- **역할:** 개인 / 기획·개발·심사 대응 전반

## 왜 미니앱인가

별도 앱 설치나 브라우저 접속 없이, 이미 쓰는 토스 앱 안에서 바로 열리게 하고 싶었습니다. 대신 대가는 분명했습니다. 토스 UI와 이질감이 없어야 하고, WebView 보안 정책을 지켜야 하며, 콘솔 심사(아이콘, 앱 이름)를 통과해야 합니다.

## 핵심 구현

### 1. 카카오맵을 iframe 없이 그리기

토스 보안 정책 때문에 `<iframe>` 방식은 차단됩니다. 카카오맵 JavaScript SDK를 불러오고, React `useRef`로 컨테이너에 지도를 직접 그렸습니다. 로컬·QR 테스트·실서비스 도메인을 카카오 디벨로퍼스 화이트리스트에 나눠 등록해 환경마다 지도가 깨지지 않게 했습니다.

### 2. 중간지점과 주변 추천

출발지 키워드를 카카오 장소 검색으로 좌표화한 뒤, 산술 평균으로 중간 지점을 계산합니다. 행정구역 역지오코딩으로 “대략적인 위치”를 보여주고, 그 좌표를 중심으로 맛집(FD6) / 카페(CE7) / 볼거리(AT4)를 찾습니다.

카카오 카테고리 검색은 조건당 최대 45개입니다. 반경을 3km → 20km까지 넓히며 여러 번 조회하고 중복을 제거해, 카테고리당 최대 50곳을 거리순으로 보여줍니다.

### 3. 장소 클릭 이후의 흐름

리스트에서 장소를 누르면 액션시트가 열립니다.

- **공유하기:** 장소명·주소·네이버지도 링크를 공유 시트로 전달
- **카카오맵으로 보기 / 네이버지도로 보기:** 전면 광고를 본 뒤 외부 지도로 이동

처음에는 “중간지점 찾기” 버튼에도 전면 광고를 넣었습니다. 검색 자체를 광고가 가로채는 UX라서 제거했고, **지도 앱으로 나갈 때만** 광고를 보여주도록 바꿨습니다. 하단 배너 광고는 유지합니다.

공유에 성공하면 프로모션 포인트를 기기당 1회 지급합니다. `.ait` 빌드는 `import.meta.env.DEV`가 false라서, 테스트 코드와 운영 코드를 플래그로 직접 전환해야 했습니다.

## 심사와 빌드에서 막힌 지점

| 이슈 | 원인 | 해결 |
|------|------|------|
| 브랜드 아이콘 반려 | 콘솔 아이콘과 `granite.config.ts` 불일치 | 콘솔에 올린 이미지 URL을 그대로 설정 |
| 미니앱 이름 반려 | `displayName`과 콘솔 등록명 불일치 | `중간지점찾기`로 통일 |
| 빌드 명령 실패 | `granite build` → `ait build` 변경 | `package.json` 스크립트 수정 후 `.ait` 재생성 |
| 주소 입력이 불편함 | 키워드만 직접 입력 | 디바운스된 연관 주소 자동완성 |

## 기술 스택

- React, TypeScript, Vite
- Apps in Toss Web Framework
- Kakao Maps JavaScript SDK (Places, Geocoder)
- Toss Design System
- TossAds Banner / FullScreen Ad, `grantPromotionReward`

## 마치며

좌표 평균을 구하는 로직보다, **토스라는 플랫폼 안에서 사용자가 실제로 이동할 수 있게 만드는 일**이 더 길었습니다. 지도 렌더링, 심사 메타데이터, 광고 타이밍, 공유와 외부 앱 이동이 한 제품으로 붙었을 때 비로소 “중간지점 찾기”가 됐습니다.
