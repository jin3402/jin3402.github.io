친구들과 만날 때 “어디서 볼까?”를 정해주는 **앱인토스 미니앱**입니다. 여러 출발지를 입력하면 중간 좌표를 계산하고, 주변 맛집·카페·볼거리까지 추천합니다.

- **GitHub:** [jin3402/midpoint-finder](https://github.com/jin3402/midpoint-finder)
- **플랫폼:** Apps in Toss WebView · TDS
- **역할:** 개인 / 기획·개발·심사 대응 전반

별도 앱 설치 없이 토스 안에서 바로 열리게 하려고 미니앱으로 만들었습니다. 대신 TDS UI, WebView 보안, 콘솔 심사(아이콘·앱 이름)를 같이 맞춰야 했습니다.

## 1. 출발지를 받는 화면

처음 열면 출발지 입력 카드가 나옵니다. 기본은 2명이지만 `+ 인원 추가`로 늘릴 수 있고, 각 카드의 `삭제`로 줄일 수 있습니다. 플레이스홀더는 `강남역, 서울역`처럼 키워드를 받도록 해 두었습니다. 정확한 도로명 주소가 없어도 카카오 장소 검색이 좌표를 찾습니다.

하단 고정 배너는 토스 광고 SDK로 붙인 영역입니다. 검색 버튼에는 전면 광고를 넣지 않았습니다. 중간지점을 계산하는 행위 자체를 광고가 가로채면 UX가 끊기기 때문입니다.

![출발지 입력 화면. 출발지 카드와 인원 추가, 중간지점 찾기 버튼](/assets/img/posts/midpoint-input.png)
{: .w-50 .shadow .rounded-10 }
_빈 입력 화면. 출발지를 늘리고 줄일 수 있고, 하단에는 배너 광고만 고정됩니다._
{: .fig-caption }

입력을 채운 예입니다. `강남구청역 7호선`, `노원역 4호선`, `을왕리해수욕장`처럼 서로 떨어진 지점을 넣으면, 단순 평균이 아니라 **실제로 만날 수 있는 중간 동네**를 찾는 문제가 됩니다. 두 글자 이상 입력하면 연관 주소 자동완성이 뜹니다. 카카오 `keywordSearch`를 250ms 디바운스해서 호출합니다.

![강남구청역, 노원역, 을왕리해수욕장을 입력한 화면](/assets/img/posts/midpoint-filled.png)
{: .w-50 .shadow .rounded-10 }
_서울 동남·북부와 인천 해수욕장처럼 거리가 먼 출발지도 같은 흐름으로 계산합니다._
{: .fig-caption }

`중간지점 찾기`를 누르면 각 키워드를 좌표로 바꾸고, 유효한 점이 2개 이상일 때만 산술 평균을 냅니다. 실패한 검색은 빼고, 2개 미만이면 에러를 보여 줍니다.

## 2. 지도 결과와 주변 추천

계산이 끝나면 카카오맵이 바로 그려집니다. 토스 WebView는 `<iframe>`을 막기 때문에 JS SDK를 `useRef` 컨테이너에 직접 붙입니다. 파란·회색·초록 핀(1, 2, 3)이 출발지고, 보라색 `M`이 중간지점입니다. 지도는 네 점을 모두 담도록 bounds를 맞춥니다.

아래 보라색 카드는 역지오코딩 결과입니다. 화면에서는 `서울특별시 양천구 신월5동`처럼 **행정동 단위**로 보여 줍니다. 좌표 숫자보다 “어느 동네인지”가 공유하기 쉽기 때문입니다. 카드 오른쪽 `공유하기`는 중간지점 자체(동네 + 네이버지도 링크)를 보냅니다.

추천 영역은 `맛집` / `카페` / `볼거리` 탭입니다. 카카오 카테고리 코드는 각각 FD6, CE7, AT4입니다. 한 조건당 최대 45개라서, 반경을 3km부터 20km까지 넓히며 중복을 제거한 뒤 거리순으로 최대 50곳을 모읍니다. 화면의 `총 45곳 중 10곳 표시 중`은 처음 10개만 보여주고 `더보기`로 늘리는 방식입니다.

![지도에 출발지 1·2·3과 중간지점 M, 양천구 신월5동 결과와 맛집 리스트](/assets/img/posts/midpoint-result.png)
{: .w-50 .shadow .rounded-10 }
_지도·중간지점 카드·카테고리 추천이 한 화면에 이어집니다. 맛집 탭에서 68m 거리의 김밥집이 맨 위에 올라온 상태입니다._
{: .fig-caption }

리스트 항목을 누르면 예전에는 지도에 마커만 찍었습니다. 지금은 **그 장소로 무엇을 할지**를 고르게 바꿨습니다.

## 3. 공유하기와 지도 앱으로 나가기

장소를 탭하면 하단 시트가 열립니다. 장소명과 도로명 주소를 보여 주고, 선택지는 세 가지입니다.

- **공유하기** — 이름, 주소, 네이버지도 검색 링크를 시스템 공유 시트로 전달합니다. 카카오톡이 있으면 거기서 바로 보낼 수 있습니다. 공유 또는 클립보드 복사에 성공하면 프로모션 포인트를 기기당 1회 지급합니다.
- **카카오맵으로 보기** — 카카오 `place_url`이 있으면 그 상세 페이지로, 없으면 이름+주소 검색 링크로 엽니다.
- **네이버지도로 보기** — `map.naver.com` 검색 URL로 엽니다.

지도 앱으로 나갈 때만 전면 광고를 보여 줍니다. `openURL`로 기기 브라우저/지도 앱을 실행하고, 미지원 환경에서는 새 탭으로 폴백합니다.

![샐러브 화곡점 액션시트. 공유하기, 카카오맵으로 보기, 네이버지도로 보기](/assets/img/posts/midpoint-actionsheet.png)
{: .w-50 .shadow .rounded-10 }
_추천 장소를 고른 뒤의 실제 다음 행동입니다. 지도 이동 전에만 전면 광고가 붙습니다._
{: .fig-caption }

## 심사와 빌드에서 막힌 지점

| 이슈 | 원인 | 해결 |
|------|------|------|
| 브랜드 아이콘 반려 | 콘솔 아이콘과 `granite.config.ts` 불일치 | 콘솔에 올린 이미지 URL을 그대로 설정 |
| 미니앱 이름 반려 | `displayName`과 콘솔 등록명 불일치 | `중간지점찾기`로 통일 |
| 빌드 명령 실패 | `granite build` → `ait build` 변경 | `package.json` 스크립트 수정 후 `.ait` 재생성 |
| 검색 버튼 전면광고 | 계산 UX가 끊김 | 광고를 지도 이동 시점으로 이동 |
| 카카오 검색 45개 제한 | API 페이지 한도 | 반경을 단계적으로 넓히며 중복 제거 |

## 기술 스택
